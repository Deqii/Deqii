# 💫 About Me:
Hello 👋

I’m an Informatics Engineering student and Full-Stack Web Developer focused on building scalable, maintainable, and production-ready web applications.

I work primarily with TypeScript, React/Next.js, Express, and relational databases (MySQL with Prisma ORM) to develop structured and efficient systems. My focus is not only on delivering features, but also on writing clean architecture, maintainable code, and performance-aware solutions.

I was selected for the DBS Foundation x Dicoding program, where I developed industry-based projects and strengthened my understanding of modern web architecture, API design, and best engineering practices.

During my 3-month internship, I contributed to real-world product development — implementing features, debugging production issues, collaborating via Git-based workflows, and working within a structured team environment. This experience helped me understand how software is built beyond tutorials — in real production scenarios.

I’m continuously improving my problem-solving skills, system design thinking, and code quality standards to grow as a professional software engineer.
